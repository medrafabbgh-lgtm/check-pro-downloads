# Check Pro downloads

Binary distribution repository for Check Pro Original, Check Pro Repair, and their companion packages.

Application source code, customer databases, account credentials, and signing keys do not belong in this repository.

## Getting an update

Use the updater inside your Check Pro application or a versioned download link provided by your administrator. Original and Repair are separate desktop products; do not substitute one installer for the other.

Published release assets are immutable. A repository commit or draft release is not an approved client update: installation eligibility is controlled separately by Check Pro's update service.
